# UAV Autonomous Navigation

受限环境下的无人飞行器自主导航案例。

本仓库用于承载案例 A 的可公开演示素材与工程说明，聚焦无 GPS、弱网/断网和工业巡检场景。涉及历史项目的商业细节、完整系统和厂商实现不在本仓库中。

## 工程范围

- 受限环境中的无人机与多机导航；
- 几何 3D SLAM 与传统运动控制；
- 基于消息中间件的任务执行、状态机调度与系统集成；
- 嵌入式部署和通信受限条件下的任务运行。

以上内容用于说明案例背景与演示边界，不代表本仓库包含完整历史系统或军用飞行器代码。
