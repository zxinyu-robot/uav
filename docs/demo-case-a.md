# 案例 A：受限环境下的无人飞行器自主导航

**案例整理与署名：zxinyu**

## 背景

案例面向无 GPS、弱网/断网和工业巡检等受限环境中的无人机与多机导航。

## 工程工作

- 自主导航系统研发；
- 状态机和任务调度；
- 多机协同调度；
- 嵌入式部署与系统集成优化；
- 基于几何 3D SLAM、传统运动控制和消息中间件的任务执行链路。
